三種用法

  1. 1

    貼上 SVG

    複製 SVG 直接貼進 HTML。樣式已經包在檔案裡，不用載任何東西，顏色跟著文字顏色走。

  2. 2

    載入 CSS，套 class

    頁面載一次 ul-icons.css（可以直接用 jsDelivr CDN），之後每個圖示只要貼精簡版 SVG。一頁用很多個時最省。

  3. 3

    當圖片用

    用 <img> 也會動，但抓不到文字顏色，會是黑色。要換色請改用前兩種。

調整

--ul-size24px大小。也可以直接改 width／height。
--ul-speed1速度倍率。2 是兩倍快，0.5 是一半。
--ul-stroke1.5線寬。
--ul-playrunning設成 paused 就暫停，例如滑過才播。
colorcurrentColor圖示顏色就是文字顏色。
.toolbar .ul-i {
  --ul-size: 20px;
  --ul-speed: 1.5;
  color: #5EEAD4;
}
.card:not(:hover) .ul-i { --ul-play: paused; }

無障礙

  • 每個圖示都有建議的 aria-label（點開圖示看得到），表達狀態時用 role="img" 加上它。
  • 只是裝飾、旁邊已經有文字時，改成 aria-hidden="true"。
  • 使用者開了「減少動態效果」時，動畫全部停下，停在一個看得懂的靜態姿勢。
  • 只動 transform、opacity、stroke-dashoffset，手機上也不會拖慢捲動。
